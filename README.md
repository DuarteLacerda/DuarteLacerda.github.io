- HTML5
- CSS3
- JavaScript
- GitHub Pages for deployment

## 🚀 Features

- 📄 About Me section
- 💼 Projects portfolio
- 📫 Contact information

## 📦 Installation

You can clone this repository if you want to run or edit the site locally:

```bash
git clone https://github.com/duartelacerda/duartelacerda.github.io.git
cd duartelacerda.github.io
```
